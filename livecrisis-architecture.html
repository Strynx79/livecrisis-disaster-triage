LiveCrisis Architecture

Hybrid triage pipeline — measured classifier decides, constrained LLM plans, dashboard displays

Measured results

  • • DistilBERT: 0.778 acc / 0.698 macro-F1 (unseen events)
  • • TF-IDF baseline: 0.720 / 0.635 · BERT: 0.784 / 0.706
  • • Zero-shot LLM: 0.700 acc but 0.415 macro-F1
  • • Single-tweet inference ~7 ms on RTX 5060

Design principle

  • • Deterministic classifier triages; LLM only plans
  • • Strict JSON schema — bad output rejected, rate measured
  • • Confidence + corroboration gate every displayed fact
  • • Degrades gracefully: classifier runs fully offline

Honest limits

  • • Tweets differ from real SMS/radio traffic; English-only
  • • LLM plan slots are demo-filled until bound to live feeds
  • • Corroboration heuristic not field-validated
  • • Never tested in a real disaster or offline network
